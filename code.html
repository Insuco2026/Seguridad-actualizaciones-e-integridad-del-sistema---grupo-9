2. Introducción a la Seguridad del Sistema Operativo

menu_book

Definición del tema

CONCEPTO CLAVE

La seguridad, actualizaciones e integridad del sistema consiste en aplicar medidas y utilizar herramientas para proteger los sistemas operativos, mantenerlos actualizados y cuidar la información almacenada en ellos. Esto incluye el uso de firewalls, antivirus, actualizaciones y copias de seguridad en Windows y Linux.

verified_user

Importancia del tema

VALOR TÉCNICO

Es importante porque permite proteger los computadores de virus, amenazas y accesos no autorizados. También ayuda a corregir errores, evitar la pérdida de archivos y mantener el sistema funcionando correctamente.

Para un técnico informático, conocer estos procedimientos es fundamental para mantener los equipos seguros, solucionar problemas y proteger la información de los usuarios.

4. Fundamentos Técnicos y Mecanismos de Defensa

filter_drama Firewall de Red y Host

Un firewall analiza el tráfico que fluye a través de los puertos TCP/UDP del sistema. Se distinguen dos filosofías principales:

STATELESS (Sin Estado) Inspecciona paquetes de forma aislada sin memoria previa de la sesión de conexión.
STATEFUL (Con Estado) Mantiene una tabla de conexiones activas; descarta paquetes que no pertenecen a flujos legítimos iniciados internamente.
pest_control Antivirus & Detección Heurística

La protección moderna trasciende la búsqueda de hashes estáticos conocidos:

  • check Firmas Hash: Comparación directa contra bases de datos de secuencias maliciosas (SHA-256).
  • check Análisis Heurístico: Detección de patrones y código ofuscado que imitan tácticas de malware conocido.
  • check Monitoreo de Comportamiento: Supervisión en tiempo real de llamadas al sistema en RAM y mitigación por sandbox.
published_with_changes Ciclo de Parches y CVEs

Las vulnerabilidades se catalogan internacionalmente como Common Vulnerabilities and Exposures (CVE).

CVE-YYYY-NNNNN
Fase 1: Descubrimiento & Notificación
Fase 2: Desarrollo de Parche del Kernel
Fase 3: Distribución vía APT / Windows Update
Fase 4: Despliegue y Validación del Servicio

inventory_2 Taxonomía de Copias de Respaldo

COMPLETO

Copia total de los datos. Mayor tiempo de ejecución y espacio en disco.

DIFERENCIAL

Copia los cambios ocurridos desde el último respaldo completo ejecutado.

INCREMENTAL

Guarda exclusivamente las modificaciones realizadas desde la última copia.

fingerprint Integridad de Archivos (FIM & Hashes)

Un algoritmo de resumen unidireccional (como SHA-256) genera una huella única invariable de 64 caracteres hexadecimales. Si un solo byte cambia en el archivo origen, el hash resultante muta por completo (Efecto Avalancha).

6. Tutoriales Operativos Dual-System

Procedimientos estandarizados para Windows 11 y Ubuntu Linux con comandos reproducibles.

local_fire_department

Tutorial 1: Configuración Defensiva del Firewall

Bloqueo de puertos no autorizados y perfiles de red
Dificultad: Inicial
window En Windows 11 (GUI)
  1. Presionar Win + I para abrir Configuración y acceder a Privacidad y seguridad → Seguridad de Windows.
  2. Hacer clic en Firewall y protección de red.
  3. Verificar que las redes Dominio, Privada y Pública tengan el estado "Activo".
  4. Ingresar a la red pública activa y marcar la casilla "Bloquear todas las conexiones entrantes, incluidas las de la lista de aplicaciones permitidas" si se está en una red Wi-Fi no confiable.
Consejo de Hardening: Para auditorías rápidas por consola PowerShell ejecutar: Get-NetFirewallProfile | Select Name, Enabled
terminal En Ubuntu Linux (UFW CLI)
  1. Abrir terminal con Ctrl + Alt + T.
  2. Establecer política estricta de denegación entrante por defecto.
  3. Permitir tráfico saliente normal del sistema.
  4. Habilitar el servicio y verificar el estado numerado de las reglas.
# Configuración base recomendada
$ sudo ufw default deny incoming
$ sudo ufw default allow outgoing
$ sudo ufw enable
$ sudo ufw status verbose
sync

Tutorial 2: Auditoría y Despliegue de Actualizaciones

Sincronización de parches acumulativos y mitigación de dependencias
Dificultad: Intermedia
window En Windows 11
  1. Abrir menú Inicio y escribir "Windows Update".
  2. Presionar el botón "Buscar actualizaciones".
  3. Esperar la descarga de parches clasificados como KB (Knowledge Base).
  4. Si el sistema solicita reiniciar, coordinar el reinicio para evitar interrupciones de servicios en caliente.
terminal En Ubuntu Linux (APT Pipeline)
# 1. Sincronizar listado de repositorios
$ sudo apt update
# 2. Consultar paquetes con parches disponibles
$ apt list --upgradable
# 3. Aplicar parches de seguridad
$ sudo apt upgrade -y
# 4. Purgar dependencias obsoletas en desuso
$ sudo apt autoremove --purge -y

Tutorial 3: Creación de Respaldos y Sumas SHA-256

Sincronización diferencial con rsync y hash check
Dificultad: Intermedia
window En Windows 11
  1. Conectar disco externo formateado en NTFS o exFAT.
  2. En Configuración → Cuentas → Copia de seguridad de Windows o mediante Historial de archivos seleccionar carpetas de código.
  3. Para validar la suma hash de un archivo empaquetado en PowerShell:
Get-FileHash -Path .\backup_proyectos.zip -Algorithm SHA256
terminal En Ubuntu Linux (rsync + tar)
# Sincronización diferencial preservando permisos
$ rsync -avzh --progress ~/Codigo/ /media/backup/
# Comprimir en un tarball con fecha actual
$ tar -czvf backup_$(date +%F).tar.gz ~/Codigo
# Generar hash de control
$ sha256sum backup_*.tar.gz > checksum.sha256

9. Diagnóstico y Resolución de Incidentes

Solución rápida a las 7 anomalías más frecuentes en administración de sistemas operativos.

INC-01

Firewall Desactivado o Bloqueado por Política

Causa: Servicios detenidos (MpsSvc en Windows / ufw daemon inactivo en Linux) o políticas heredadas corruptas.

# Solución en Windows PowerShell:
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True
# Solución en Ubuntu Linux:
sudo systemctl restart ufw && sudo ufw enable
INC-02

Error 0x80070422 en Windows Update

Causa: El servicio Windows Update (wuauserv) se encuentra en estado Deshabilitado o con dependencias fallidas.

# Restablecer servicio en CMD (Administrador):
sc config wuauserv start= auto
net start wuauserv
INC-03

Bloqueo de Repositorios (lock-frontend) en APT

Causa: Otro proceso en segundo plano (como unattended-upgrades) mantiene tomada la base de datos de dpkg.

# Identificar y liberar proceso en Linux:
sudo fuser -vki /var/lib/dpkg/lock-frontend
sudo dpkg --configure -a
INC-04

Falta de Espacio en Partición /root o Unidad C:

Causa: Acumulación desmedida de logs, temporales de actualización o paquetes .deb cacheados.

# Limpieza de caché APT en Linux:
sudo apt clean && sudo journalctl --vacuum-time=3d
# Limpieza en Windows (PowerShell):
Clear-RecycleBin -Force; cleanmgr.exe /verylowdisk
INC-05

Corrupción del Sistema de Archivos por Corte de Energía

Causa: Inconsistencias lógicas en la estructura de bloques NTFS o ext4.

# Reparación en Windows (CMD Admin):
sfc /scannow && DISM /Online /Cleanup-Image /RestoreHealth
# Reparación en Linux (partición desmontada):
sudo fsck -yf /dev/sdXn
INC-06

Permiso Denegado al Ejecutar Scripts de Respaldo

Causa: Ausencia de bit de ejecución en Linux o política ExecutionPolicy Restrictive en PowerShell.

# Conceder ejecución en Linux:
chmod +x ./backup_script.sh
# Ajustar política PowerShell:
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
INC-07

Unidad Externa en Modo Solo Lectura

Causa: Sistema de archivos montado con errores defensivos (ro flag) o bloqueo NTFS por Fast Startup.

# Remontar con permisos de lectura/escritura en Linux:
sudo mount -o remount,rw /media/usuario/BackupDrive
